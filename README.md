# Community Science Museum

## Semester Project 1

[View SP1](https://kimthenriksen.github.io/SP1/)

## Description

Community Science Museum is my Semester Project 1 at Noroff.

I created a website for a science museum aimed at children, families, teachers and researchers.

The goal was to create a responsive and user-friendly website where visitors can find information about the museum.

## Features

- Responsive design
- Mobile navigation
- Exhibiton and activity information
- Information for children, teachers and researchers
- Visitor information
- Contact page
